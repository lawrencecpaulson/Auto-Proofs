# Green and Cauchy–Pompeiu

This staged AFP entry contains the planar Green and Cauchy results originally
developed with Stokes. Its single session, `Green_Cauchy_Pompeiu`, imports the
`Stokes` session for shared local integration and cutoff lemmas.

Theorems include `Green_rectangular_union_polygonal_contours`,
`green_ac_contour_wirtinger_dbar_winding_area`,
`green_cauchy_pompeiu_rectangle_interior`, and
`green_ac_contour_dbar_winding_local_C1`.

The existing AFP `Green` entry proves a theorem for domains bounded by graphs.
This entry adds rectangular unions with T-junctions, decomposition into
oriented closed walks, absolutely continuous path results, winding-weighted
identities, and Cauchy–Pompeiu. Its relationship to that entry should be made
explicit in the submission abstract.
