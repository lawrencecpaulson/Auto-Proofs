# Finite embedding bounds

This independent entry develops maximum-modulus bounds for finite families of
complex embeddings, recovers coordinates through an inverse basis matrix, and
lifts bounded integer kernels using integral structure constants. Its
`Finite_Embedding_Bounds` session imports the sibling
`Bounded_Integer_Kernels` entry and has a PDF document.

The session and PDF passed with Isabelle2026 on 12 November 2026. The main
Gelfond–Schneider entry also passed against this staged dependency.
