\title{Bounded Integer Kernels}
\author{OpenAI Codex}
\maketitle

\begin{abstract}
We prove that an underdetermined integer matrix has a nonzero integer
kernel vector with explicitly bounded coordinates. One bound uses
Hadamard's determinant estimate. A sharper pigeonhole argument gives
a counting form of Siegel's lemma and the coordinate bound
$(q\max(1,B))^{p/(q-p)}$ for a $p\times q$ matrix with entries bounded
in absolute value by $B$, where $0<p<q$. We also retain a linear bound
when the number of columns is at least twice the number of rows.
The development uses the AFP entries Jordan Normal Form and Linear
Inequalities. It was motivated by the integer-matrix theorem in
Mathlib's \texttt{NumberTheory/SiegelsLemma}, due to Fabrizio Barroero,
Laura Capuano, and Amos Turchet.
\end{abstract}
