# Primitive real characters

This entry classifies primitive real Dirichlet characters by assembling their
local prime-power characters with the Chinese remainder theorem and quadratic
reciprocity. The public theorem `primitive_real_character_discriminant`
produces a fundamental discriminant and the odd-prime Legendre formula,
packaged as `quadratic_real_character_data`.

The entry uses general AFP libraries and does not import `No_Siegel`. Green's lattice character locale and the bridge to it remain in `No_Siegel`.
