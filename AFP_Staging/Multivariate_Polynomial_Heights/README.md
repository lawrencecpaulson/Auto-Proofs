# Projective Heights of Multivariate Polynomials

This entry defines a projective coefficient height for rational multivariate
polynomials using primitive integral representatives. It proves existence of
such representatives, invariance under nonzero scalar multiplication, and
multiplicativity of height for polynomials in disjoint sets of variables.
It also collects elementary height facts for rational points.

The entry depends on `Multivariate_Hasse_Derivatives` for its general
multivariate polynomial algebra lemmas. Build with Isabelle2026 and the
matching AFP checkout:

    isabelle build -b -d /path/to/afp/thys -d /path/to/Multivariate_Hasse_Derivatives -d . Multivariate_Polynomial_Heights
