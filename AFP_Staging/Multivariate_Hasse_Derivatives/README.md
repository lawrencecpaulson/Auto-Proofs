# Multivariate Hasse Derivatives

This entry develops finite exponent boxes, multivariate polynomial translation,
Taylor coefficients, Hasse derivatives, and their support and composition laws.
The derivative calculus is stated over general commutative coefficient rings;
several support formulas use an integral domain. The weighted polynomial index
and its application to Diophantine approximation remain in the Roth entry.

The entry uses the AFP `Polynomials` session. Build with Isabelle2026 and the
matching AFP checkout:

    isabelle build -b -d /path/to/afp/thys -d . Multivariate_Hasse_Derivatives
