# Stokes development notes

These are the planning, source-audit, and progress files used while developing
the `Stokes` AFP entry in the sibling directory. They are preserved for
reference. `DEVELOPMENT_README.md` and `PROOF_STATUS.md` describe earlier
multi-session layouts and should be read as historical records; the current
session configuration is `../Stokes/ROOT`. Earlier theory filenames in
these notes have the `Stokes_` prefix. Current filenames omit that prefix,
apart from `Stokes_Local.thy`.
